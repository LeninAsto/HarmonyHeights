# Harmony Heights

Sitio institucional académico de música y artes escénicas, creado a partir de los requisitos del trabajo final.

## Abrir el proyecto

- **Solo frontend:** abre `index.html` en el navegador.
- **Frontend + backend:** instala PHP 8, abre una terminal en esta carpeta y ejecuta `php -S localhost:8000`.

Consulta [INFORME_TECNICO.md](INFORME_TECNICO.md) para la justificación completa y [GUIA_EXPOSICION.md](GUIA_EXPOSICION.md) para preparar la presentación.

## Herramientas para el visitante

Los botones flotantes disponibles en todas las páginas permiten abrir ajustes de accesibilidad, activar o detener una melodía ambiental generada por el navegador y volver al inicio de una página larga. La música nunca se reproduce automáticamente.

La presentación HTML con estilo Material Design 3 se encuentra en `../trabajo final/presentacion.html`.
