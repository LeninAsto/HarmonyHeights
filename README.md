# Harmony Heights

Proyecto académico de música y artes escénicas. El sitio está en `docs`.

Ejecutar desde esta carpeta: `python -m http.server 8000 --directory docs`.

Abre http://localhost:8000. Consulta [la guía del proyecto](docs/README.md) y [la activación de Firebase](docs/FIREBASE.md).

Para publicar automáticamente los cambios de `main`, sigue [GitHub Pages](docs/GITHUB_PAGES.md). El workflow prepara `docs`, excluye el backend PHP y despliega el sitio estático.
